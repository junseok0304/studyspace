수업노트 작성 팁

나중에 다시 보기 좋은 노트 쓰기

수업 내용을 모두 받아 적을 필요는 없어요. 중요한 흐름과 궁금한 점을 먼저 적고, 수업이 끝난 뒤 필요한 부분을 보태 보세요.

수업 중 메모 · 수업 후 정리
01

핵심 개념을 짧게 적기

개념이 나오면 아래 질문을 떠올려 보세요.

  • 무엇인지 한 문장으로 말하면?
  • 왜 필요하고, 어떤 문제를 해결하나?
  • 어떤 순서로 동작하나?
  • 코드나 상황으로 예를 들 수 있나?
02

강조한 내용은 표시해 두기

시험·과제·실습 이야기가 나오면 나중에 찾기 쉽도록 따로 남겨 두세요.

  • 시험이나 과제에 나온다고 한 내용
  • 여러 번 설명한 개념
  • 서로 헷갈리기 쉬운 개념의 차이
  • 자주 틀리는 부분과 주의점
03

헷갈리는 점은 질문으로 남기기

모르는 부분을 표시하고, 무엇을 확인할지 함께 적어 두세요.

  • 어디까지 이해했는지
  • 어떤 설명에서 막혔는지
  • 교재나 강의자료에서 다시 볼 곳
  • 다음 수업에서 물어볼 내용
04

코드와 예제는 실행 결과까지

코드만 옮겨 두면 나중에 맥락을 놓치기 쉬워요. 실행 조건과 결과도 함께 적어 보세요.

  • 입력값과 실행 조건
  • 실행 결과나 오류 메시지
  • 핵심이 되는 코드 한두 줄
  • 내 말로 풀어 쓴 동작 원리
05

수업 끝나고 5분만 정리하기

짧게 돌아보는 것만으로도 다음에 복습할 부분이 또렷해져요.

  • 오늘 기억할 내용 세 가지
  • 아직 자신 없는 부분 하나
  • 다음 수업 전까지 할 일
06

다시 펼쳤을 때 바로 이해되게

몇 주 뒤에 읽어도 무슨 내용인지 알 수 있으면 잘 정리된 노트예요.

  • 한 문단에는 한 가지 내용만
  • 제목은 구체적으로 붙이기
  • 수업 내용과 내 생각을 구분하기
  • 과목과 수업 날짜를 적어 두기
