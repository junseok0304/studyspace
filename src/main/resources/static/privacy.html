회원가입으로 돌아가기

개인정보 처리방침 및 수집·이용 안내

로컬 개발 테스트용 초안 · 버전 2026-09-19-draft

개인정보 처리 주체·담당자·연락처는 운영 공개 전에 확정할 예정입니다. 이 초안은 현재 구현된 로컬 테스트 기능을 설명합니다.

수집 항목과 목적

이메일 가입 시 이메일, 비밀번호의 단방향 해시, 닉네임을 저장하여 계정을 생성하고 로그인에 사용합니다. 카카오 가입 시 카카오 사용자 식별자와 제공받은 이메일·닉네임을 계정 식별에 사용합니다. 약관 버전과 동의 시각을 가입 동의 확인을 위해 저장합니다.

학습 기록과 쿠키

사용자가 작성한 학기·과목·노트는 저장과 재조회 목적으로 보관합니다. 로그인 유지와 요청 확인에 필요한 쿠키를 사용합니다.

보유 기간과 삭제

계정과 학습 자료는 테스트 계정을 유지하는 동안 보관하며, 삭제 요청 시 운영자가 로컬 저장소에서 삭제합니다. 운영 서비스의 탈퇴 처리 기한, 백업 보존 기간 및 법령상 보관 대상은 공개 전에 확정하여 안내합니다.

학교 연동과 외부 서비스

카카오 인증 시 카카오와 인증 정보를 주고받습니다. 학교 연동을 선택하고 저장에 동의하면 LMS 아이디와 비밀번호를 암호화해 보관합니다. 등록 시 성공회대학교 포털과 LMS로 로그인 정보를 전송하여 확인하고, 동기화 시 포털·종합정보시스템·수강신청 사이트에 로그인하여 과목과 시간표를 조회합니다. 연동을 해제하면 저장된 학교 로그인 정보를 삭제하며, 이미 가져온 과목과 노트는 유지합니다. AI 기능은 실제 제공 전에 전송 항목, 제공자와 처리 조건을 별도로 안내합니다.

동의 거부와 권리 행사

수집·이용 동의를 거부할 수 있으나 계정 기반 서비스 가입은 진행할 수 없습니다. 열람·정정·삭제·동의 철회는 현재 로컬 테스트 운영자에게 요청할 수 있습니다. 공개 전 상시 문의 경로를 게시합니다.
