# StudySpace 모바일 학습 공간과 생성 결과 초기화

작성일: 2026-10-01

## 목표

로그인한 사용자가 휴대전화 화면에서 과목과 노트를 차례로 선택하고 노트, 강의자료, 녹음, 요약, 인포그래픽, 퀴즈, 플래시카드를 사용할 수 있게 한다. 인포그래픽은 글과 관계 그래픽을 중심으로 표현한다. 로컬 DB의 모든 계정에서 기존 AI 생성 결과와 관련 통계를 초기화한다.

## 범위와 완료 조건

- [x] 모바일 홈에서 과목 목록으로, 과목에서 노트 목록으로, 노트에서 각 학습 기능으로 이동할 수 있다.
- [x] 360px 및 390px 화면의 주요 화면에 가로 넘침이 없다. 주요 버튼의 포커스 스타일과 터치 크기를 제공한다.
- [x] 노트 편집, 강의자료 업로드, 녹음 조작, AI 학습 탭과 생성/풀이/복습 화면의 모바일 진입 경로를 제공한다.
- [x] 녹음 안내에 사전 허락을 받은 강의만 녹음하도록 문구를 추가한다.
- [x] 인포그래픽 생성과 표시에서 불필요한 아이콘을 없애고 텍스트와 관계 그래픽을 우선한다.
- [x] 로컬 DB의 모든 계정에서 요약·인포그래픽 생성 결과, 퀴즈·풀이 기록, 플래시카드·복습 기록을 삭제한다. 대시보드 퀴즈 기록과 오늘 학습 카드 통계가 초기 상태로 표시된다.
- [x] 노트, 과목, 첨부 원본, 녹음, 계정 정보는 유지한다.
- [x] 자동화 테스트와 브라우저 모바일 화면에서 흐름을 확인한다.
- [x] 변경 사항을 커밋·푸시한다.

## 구현 메모

- 모바일 학습 공간은 현재 화면 상태를 이용해 과목, 노트, 학습 패널을 한 화면씩 보여준다.
- 기존 노트 편집 보호와 녹음 상태 전환을 그대로 사용한다.
- 노트를 여는 것만으로 생성 결과가 다시 생기지 않도록 각 AI 학습 항목을 열 때만 해당 자료를 생성한다.
- 데이터 삭제는 로컬 H2 DB에 한정한다. 삭제 전후의 테이블 건수를 기록한다.

- [x] 기존 화면, 인포그래픽 생성 코드, 저장 스키마 조사 시작.
- [x] 모바일 화면 전환과 전용 스타일 구현. 화면 검증 대기.
- [x] 인포그래픽 아이콘 제거와 설명 중심 생성 형식 적용. 화면 검증 대기.
- [x] 로컬 DB 초기화 및 테이블 건수 검증.

- [x] 커밋·푸시.

## 후속 개선

- [x] 요약 생성 대기·실패 안내 상자가 요약 본문 최대 너비 제한에 묶이지 않도록 학습 영역 전체 너비로 표시한다.
- [x] 기존 퀴즈 문항을 새 퀴즈 생성 문맥에서 제외하고, 동일 문구의 재생성을 저장 전에 거른다. 로컬 모의 퀴즈도 이전 정답 내용을 재사용하지 않는다.
- [x] 노트 열람 화면 본문 H1 크기를 데스크톱 22px, 모바일 20px로 낮춘다.
- [x] Java 컴파일과 프런트엔드 빌드 통과. 테스트는 실행하지 않았다.
- [x] 기존 퀴즈 문항 조회는 현재 사용자와 해당 노트로 범위를 제한한다.
- [x] 후속 변경을 커밋·푸시한다.

## 모바일 화면 후속

- [x] 모바일 폭에서 뽀모도로를 숨기고 타이머 때문에 추가되던 화면 하단 여백을 없앤다.
- [x] 퀴즈·플래시카드의 개수 선택과 생성 버튼을 제목 아래 전체 너비에 정렬한다.
- [x] 데스크톱 뽀모도로가 대시보드에서 자동 축소되지 않도록 하고, 별도 접기 설정이 없으면 기본 크기로 표시한다.
- [x] 선택되지 않은 작성 팁 메뉴를 다른 학습 메뉴와 같은 중립 글자색과 배경으로 표시하고, 선택·호버 시에만 강조한다.
- [x] 로그인 실패 시 인증 API의 401 응답으로 로그인 화면이 새로고침되지 않도록 해 오류 안내를 유지한다.
- [x] 로그인 실패 제한을 이메일별 15분 내 5회에서 8회로 완화해 정상적인 재시도 여유를 늘리면서 rate limit은 유지한다.
- [x] 2026년 1학기 LMS의 새 `content-container` 과목 카드 응답을 파싱해 과목명·분반·시간을 정상적으로 불러온다.
